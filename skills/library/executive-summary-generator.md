# executive-summary-generator

Преобразует сложные бизнес-данные в краткие и действенные резюме для руководителей C-suite.

## skill_prompt

Шаги для выполнения этой задачи: 1. Используйте инструмент capture_thought для сохранения предоставленных бизнес-данных. 2. Примените инструмент search_thoughts для поиска связанных мыслей и данных. 3. Используйте инструмент thought_stats для анализа собранной информации. 4. Сформируйте резюме, следуя шаблону, и используйте инструмент capture_thought для сохранения итогового документа. 5. Обновите статус или содержание с помощью update_thought, если необходимо.
