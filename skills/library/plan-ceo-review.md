# plan-ceo-review

Обзор плана для CEO/основателя. Переосмыслите проблему и найдите продукт на 10 звезд.

## skill_prompt

Используйте инструменты Open Brain для выполнения этого навыка: сначала выполните search_thoughts, чтобы найти связанные мысли. Затем, в зависимости от контекста, используйте capture_thought для сохранения новых идей или update_thought для обновления существующих. Если необходимо, примените list_projects для просмотра текущих проектов и thought_stats для анализа статистики памяти.
