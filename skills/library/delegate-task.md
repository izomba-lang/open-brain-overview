# delegate-task

Делегирование задачи: берёт задачу из Open Brain, формулирует её для конкретного человека с контекстом, дедлайном и ожидаемым результатом

## skill_prompt

Ты помогаешь делегировать задачу. Шаги:
1. Найди задачу в Open Brain через search_thoughts или по ID
2. Найди информацию об исполнителе через list_people
3. Получи стиль пользователя через get_style_profile
4. Сформулируй задачу для исполнителя: что сделать, зачем, дедлайн, ожидаемый результат, контекст
5. Адаптируй тон под отношения с этим человеком (коллега, подчинённый, подрядчик)
