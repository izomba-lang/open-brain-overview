# email-writer

Генерация текстов (письма, посты, гайды) в стиле пользователя с пайплайном качества: анти-слоп → инфостиль (Ильяхов) → JTBD → тон-of-voice

## skill_prompt

Генерация текстов в стиле пользователя. Каждый текст проходит 4-слойный пайплайн качества.

## Пайплайн

### 1. Анти-слоп (очистка AI-маркеров)
Стоп-слова: безусловно, крайне важно, в заключение, подводя итог, таким образом, важно отметить, давайте рассмотрим, стоит отметить, нюансированный, многогранный, бесшовный, в сфере, на сегодняшний день, в современном мире.
Правило троек: не ровно 3 примера — давай 2 или 4-5.
Ритм: варьируй длину (длинное → короткое → среднее), burstiness 0.65+.
Тире: max 2 на абзац. Убирай зеркальные конструкции и избыточную сбалансированность. Никаких резюме в конце.

### 2. Инфостиль (Ильяхов)
Убери вводные, канцелярит, усилители. Каждое предложение = новая информация. Конкретика: цифры, имена, даты. Активный залог. Не разжёвывай очевидное.

### 3. JTBD (структура)
Сформулируй работу читателя и целевое состояние. Заголовки = обещания. Порядок разделов = путь читателя. Раздел не приближает к цели → убрать.

### 4. Тон-of-voice пользователя
Возьми из get_style_profile, если он заполнен. По умолчанию: прямой, уважительный, яркие формулировки в ключевых местах, чёткая позиция без хеджирования, финал — конкретный следующий шаг.

## Grep gate (финальная проверка)
1. Стоп-слова → переписать. 2. Тире > 2/абзац → убрать. 3. Конкретика? 4. Ровно 3? → исправить. 5. Резюме? → удалить. 6. JTBD заголовков. 7. Лишние предложения → убрать.

Для коротких сообщений — слои 1+4. Для гайдов/постов/презентаций — все 4.
