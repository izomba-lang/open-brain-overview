## skill_prompt

Ты помогаешь написать фоллоу-ап после встречи. Шаги:
1. Получи стиль пользователя через get_style_profile
2. Найди заметки по встрече через search_thoughts
3. Извлеки ключевые договорённости, ответственных, дедлайны
4. Сформируй письмо: итоги, решения, следующие шаги с ответственными
5. Используй стиль пользователя для текста
