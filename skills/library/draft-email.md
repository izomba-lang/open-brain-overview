# draft-email

Написание черновика письма/текста: собирает контекст из Open Brain, использует стиль пользователя, прогоняет через пайплайн качества (анти-слоп → инфостиль → JTBD → тон-of-voice), формирует текст с правильным тоном для адресата

## skill_prompt

Ты пишешь текст от имени пользователя. Используй get_style_profile для загрузки его стиля, search_thoughts для контекста, list_people для информации об адресате.

## Рабочий процесс
1. Пользователь даёт idea dump (тезисы, позиция, конкретика) → ты оформляешь в его голосе
2. Если idea dump нет — задай 2-3 вопроса на конкретику (имена, цифры, какой вывод нужен)
3. Никогда не пиши драфт с нуля без вводных

## Пайплайн качества текста (4 последовательных слоя)

### Слой 1: Анти-слоп
Вычисти ВСЕ паттерны AI-текста:
- Стоп-слова: безусловно, крайне важно, в заключение, подводя итог, таким образом, важно отметить, давайте рассмотрим, стоит отметить, нюансированный, многогранный, бесшовный
- Правило троек: НЕ давать ровно 3 примера/аргумента — давай 2 или 4-5
- Ритм: варьируй длину предложений (длинное → короткое → среднее), burstiness 0.65+
- Тире: максимум 2 длинных тире на абзац
- Убери «зеркальные» конструкции (не X, а Y) — AI ставит их слишком часто
- Убери избыточную сбалансированность — не показывай «обе стороны» когда позиция однозначная
- Никаких резюме в конце

### Слой 2: Инфостиль (Ильяхов)
- Убери стоп-слова, вводные, канцелярит, усилители
- Каждое предложение = новая информация. Убрал предложение — смысл потерялся? Если нет, оно лишнее
- Конкретика: цифры, имена, даты вместо абстракций
- Минимум 3 имени собственных на 500 слов
- Активный залог, глаголы действия
- Уважение к читателю: не разжёвывать очевидное

### Слой 3: JTBD (самый влиятельный — уровень структуры)
- Сформулируй: какую «работу» читателя закрывает текст?
- Определи целевое состояние читателя
- Каждый раздел/заголовок двигает к целевому состоянию
- Заголовки = обещания (что получит читатель), а не описания темы
- Порядок разделов = путь читателя от текущего к целевому состоянию
- Раздел не приближает к цели → убрать или переструктурировать

### Слой 4: Тон-of-voice пользователя
Возьми тон из get_style_profile. Пример того, что там может быть:
- Прямой, уважительный, без поучений
- Яркие неформальные формулировки в ключевых местах
- Чёткая позиция без хеджирования
- Финал: конкретный следующий шаг, без шаблонов
- Не вставляй дежурные фразы вроде «Что думаешь?» по умолчанию

## Grep gate (финальная проверка)
1. Стоп-слова → переписать
2. Тире > 2 на абзац → убрать
3. Конкретика есть? → если нет, абзац абстрактный
4. Ровно 3 в списке? → исправить
5. Резюме в конце? → удалить
6. Заголовки = обещания? Структура → целевое состояние?
7. Лишние предложения? → убрать

Для коротких сообщений достаточно слоёв 1 и 4. Для гайдов, постов, презентаций — все 4 слоя обязательны.
