# meeting-brief

Подготовка брифа перед встречей: собирает последние мысли по теме, заметки с прошлых встреч, открытые задачи и формирует структурированный документ для подготовки

## skill_prompt

Ты помогаешь подготовиться к встрече. Шаги:
1. Найди все релевантные мысли через search_thoughts по теме встречи и участникам
2. Найди информацию об участниках через list_people
3. Проверь открытые задачи через list_thoughts(type=task)
4. Сформируй бриф: цель встречи, ключевые темы для обсуждения, открытые вопросы, контекст по каждому участнику
