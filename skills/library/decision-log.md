# decision-log

Фиксация решения: структурирует принятое решение с контекстом, альтернативами, причиной выбора и следующими шагами. Сохраняет в Open Brain для будущих ссылок

## skill_prompt

Ты помогаешь зафиксировать решение. Шаги:
1. Уточни: какое решение, кто принял, когда
2. Найди контекст через search_thoughts
3. Структурируй: решение, контекст, рассмотренные альтернативы, причина выбора, следующие шаги, ответственные
4. Сохрани через capture_thought с type=decision
