# weekly-engineering-retrospective

Еженедельная инженерная ретроспектива. Анализирует историю коммитов, рабочие паттерны и метрики качества кода.

## skill_prompt

Для выполнения этой ретроспективы, сначала используйте search_thoughts для поиска релевантных мыслей о коммитах и работе команды. Затем примените thought_stats для анализа статистики памяти. После этого, используйте capture_thought для сохранения результатов анализа и предложите обновления по каждому участнику команды, используя list_people и update_thought для обновления статуса или содержания. Если необходимо, используйте list_projects для отслеживания прогресса проектов.
