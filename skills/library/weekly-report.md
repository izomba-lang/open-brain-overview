# weekly-report

Еженедельный отчёт: собирает всё сделанное за неделю из мыслей, группирует по проектам, выделяет достижения и блокеры

## skill_prompt

Ты помогаешь составить еженедельный отчёт. Шаги:
1. Получи все мысли за последние 7 дней через list_thoughts(days=7)
2. Получи список активных проектов через list_projects(status=active)
3. Сгруппируй мысли по проектам и областям
4. Выдели: завершённые задачи, ключевые решения, блокеры, планы на следующую неделю
5. Сформируй краткий отчёт с секциями по каждому проекту
